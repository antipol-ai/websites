Drei Ebenen der Anpassung

Jede Komponente kann auf drei Ebenen angepasst werden - von einfach bis tief. Die erste Ebene passiert automatisch ueber das Theme, die weiteren erfordern bewusste Entscheidungen.

Ebene 1 - Automatisch

Token-Level

Farben, Radii, Fonts, Spacing - alles, was ueber CSS Custom Properties definiert ist. Aendert sich automatisch je nach Brand-Theme.

/* tokens.json aendern -> build-tokens.mjs -> CSS */ --card-radius: 4px /* ANTIPOL: eckig */ --card-radius: 16px /* Momance: rund */
Ebene 2 - Props & Slots

Komponenten-API

Jede Komponente bietet Props (z.B. variant, layout) und Slots fuer flexible Inhalte.

<Hero layout="two-column"> <!-- ANTIPOL --> <Hero layout="centered"> <!-- Momance -->
Ebene 3 - Tief

Scoped Styles & Overrides

In der .astro-Seite koennen Styles ueber :global() oder eigene CSS Custom Properties ueberschrieben werden.

.my-section :global(.card) { padding: 3rem; border-style: dashed; }

Starwind UI - Erweiterbare Komponentenbibliothek

Starwind UI ist eine shadcn/ui-Portierung fuer Astro mit Tailwind v4. Aktuell sind keine Starwind-Komponenten installiert - bei Bedarf via npx starwind add [name]. Jede Komponente landet als editierbare .astro-Datei in eurem Repo.
